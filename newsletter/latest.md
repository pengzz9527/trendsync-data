🔥今日最热

今天 GitHub 上最火的项目依然是 **build-your-own-x**，**50万星**的体量说明大家是真的想手撸技术栈，而不是光看教程。另一个值得注意的爆点是 **Gemini 3.5 Flash** 在 Hacker News 上狂揽 **749票**，523条讨论炸了锅——Google 这波更新让不少开发者觉得“终于能打了”。对了，**Google 改了搜索框**也拿了504票，但评论区基本在吐槽：改来改去不如把搜索结果做好点。

📈值得关注

本周新星里有个有意思的项目：**zerolang**，才 **3615星**但用 C 语言写，目标是“零开销抽象”，感觉是给嵌入式和高性能场景准备的。另一个是 **facebookresearch/vggt-omega**，虽然只有 **1267星**，但挂了个 Python 标签，估计是视觉模型相关。Dev.to 上有个帖子特别扎心——《Cloudflare 把我的生产模型废弃了，推荐升级方案要每百万 token 4美元》，评论区一片“大厂收割机”的感叹。

🏷语言趋势

今天语言热度榜上 **TypeScript 和 Python 并列第一**，各占6个项目，但 TypeScript 在 GitHub Top8 里直接霸了三个坑（freeCodeCamp、OpenClaw、Developer Roadmap）。有意思的是 **Shell 脚本**居然挤进了前五，说明 DevOps 和自动化配置的需求一直没降。另外 **JavaScript** 只有3个项目上榜，感觉大家都在往 TS 迁移，原生 JS 项目越来越像“古董”。

💡小编视角

今天最让我感慨的是 Hacker News 上那个 **《Everything in C is undefined behavior》**——虽然只有81票，但评论里吵了81楼，核心观点是“C 标准把太多东西丢给编译器，写代码像在走钢丝”。另一个让我笑出声的是 **Hermes Just Killed OpenClaw**，标题党但内容确实猛：Hermes 这个新工具号称能“秒杀” OpenClaw 的 AI 代理能力，技术迭代快得让人喘不过气。最后，掘金上那个《前端开发必装 Skill 清单》挺实在，建议所有用 AI 写代码的都去看看——别光顾着爽，得知道哪些提示词真能提升效率。
