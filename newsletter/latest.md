🔥今日最热

GitHub 本周 Top8 几乎全是“自学圣经”——**build-your-own-x** 以 50 万星继续封神，教人手撸数据库、Git、操作系统，比任何付费教程都硬核。**awesome** 和 **freeCodeCamp** 紧随其后，说明开发者对“系统化学习”的饥渴从未消退。有趣的是 **system-design-primer** 冲到第八，34 万星，这玩意儿是面试大厂的必读物，看来“造火箭”技能依然是行情硬通货。

📈值得关注

本周新星里，**OrcaSlicer-bambulab** 以 5856 星领跑，C++ 写的 3D 打印切片器，说明开源硬件社区正在“卷”工具链。**html-anything** 只有 3129 星但纯 HTML 实现，这思路反直觉——大家都在堆框架时，有人用最基础的东西搞事情。HN 上最热闹的是 **Files.md**，140 个赞说要替代 Obsidian，但 65 条评论里一半在吵“Markdown 笔记工具到底要不要本地优先”。另一个有趣的是 **Linux 安全邮件列表“几乎不可管理”**，103 赞，内核社区的人吐槽补丁审查已经快崩了，这比任何 AI 新闻都更真实地反映了开源基础设施的脆弱。

🏷语言趋势

这周 TypeScript 和 Python 各 6 次上榜，打成平手。TypeScript 赢在“全栈泛化”——**openclaw** 和 **developer-roadmap** 都是 TS 写的，前者做跨平台 AI 助手，后者做交互式学习路线图。Python 则靠 **public-apis** 和 **free-programming-books** 这种“资源聚合器”撑场面。Shell 只出现 2 次，但别小看它，**build-your-own-x** 里大量自动化脚本就是 Shell 写的，它像胶水一样粘合着整个开源生态。

💡小编视角

今天最让我感慨的是 **DeepSeek 悄悄跑在你用的 AI 工具里**——Dev.to 上那篇 19 赞的文章揭露了真相：很多标榜“自研模型”的产品底层其实调的是 DeepSeek API。这不是坏事，但说明 AI 行业的“品牌溢价”正在被开源模型瓦解。另一个反直觉的发现是 **Bidet AI**，一个在本地跑 Gemma 4 的“农场医生”，3 个赞却让我眼前一亮——当所有人都盯着云端大模型时，有人在手机上用 4B 参数模型解决实际农业问题，这才是技术落地的正确姿势。最后，**Android Studio 越用越卡**那篇掘金文章 15 赞，评论区炸了，有人说是 Gradle 的锅，有人怪 Kotlin 编译慢，但没人提 JetBrains 的 Fleet——这恰恰说明 IDE 战争还没真正开始。
