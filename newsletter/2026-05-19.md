🔥今日最热

今天 GitHub 上最炸裂的项目还是那个教人“手搓一切”的 **build-your-own-x**，星数已经飙到 **502k**，比第二名 **awesome** 多了快四万星。这说明啥？大家是真的受够了黑盒，想亲手把 Redis、Git 甚至数据库从零造出来——这种“底层快感”比刷 LeetCode 爽多了。另外 **freeCodeCamp** 和 **public-apis** 双双破 43 万星，说明自学和薅免费 API 依然是刚需。

📈值得关注

本周新星里最亮眼的是 **YellowKey**（**3478★**），虽然语言标注是问号，但光看名字就感觉是个搞键盘或安全的小工具。更值得盯的是 **facebookresearch/vggt-omega**（**1073★**），Meta 这波在 CV 领域又放了个大招，虽然星数不高但背后技术含量极高。HN 上最热闹的是 **Anthropic 收购 Stainless**（433票，291评），大伙都在猜这是要自己搞 API 网关还是补全工具链——反正 Claude 的生态越来越封闭了。

🏷语言趋势

今天语言榜上 **TypeScript** 和 **Python** 各占 6 个项目，打成平手，但 TS 的势头明显更猛——**openclaw**（37 万星）这种个人 AI 助手项目都能用 TS 写，说明前端搞 AI 已经不是玩票了。**Shell** 只出现 2 次，但别忘了 **build-your-own-x** 里大量 Shell 脚本，真正的硬核玩家都在背后默默写 bash。

💡小编视角

今天 Reddit 上有个帖子特别扎心：**“说‘不’的工程师是 ZIRP 时代的产物”**。意思是零利率时期大家敢随便拒绝需求，现在都得跪着写代码。另一个帖子说 **“最好的工程师说不清自己知道什么”**——这让我想起那些能徒手调优数据库但写不出文档的大神。另外 **npm 又翻车了**，314 个包被黑，连 @antv 都中招，建议大家最近装包前先看一眼 dependencies 树。最后，掘金那篇 **“一套 Rust 核心跑通 Tauri + React Native”** 值得细读，跨端方案越来越像乐高，但核心逻辑用 Rust 写才是真·一劳永逸。
