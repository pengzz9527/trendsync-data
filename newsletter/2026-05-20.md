🔥今日最热

今天 GitHub 上最炸的还是 **build-your-own-x**，快 **50.3 万星**了，这项目教你怎么从零手撸各种技术（数据库、Git、编译器），简直是编程界的“自己动手丰衣足食”。另一边，**freeCodeCamp** 和 **public-apis** 也稳在 44 万和 43 万星上下，说明大家还是爱白嫖学习资源和免费 API。有意思的是 **openclaw** 这个 AI 助手项目冲到 37 万星，跨平台、任意系统都能跑，看来“个人 AI 管家”已经成了刚需。

📈值得关注

本周新星里最亮眼的是 **zerolang**，才 3862 星但用 C 语言写，感觉是个轻量级新语言在憋大招。HN 上最炸的是 **Meta 在阿拉伯地区封禁人权账号**（516 赞），评论区吵翻了，还有人爆料 **CISA 自己把 GitHub 密钥泄露了**（Reddit 478 赞），这波操作真够魔幻的。另外 **Raven Software 2013 年公开《绝地学院》源码**（1660 赞），开发者注释里全是加班吐槽，程序员看了都得会心一笑。

🏷语言趋势

本周语言榜上 **TypeScript** 和 **Python** 并列第一（各 6 个项目），TypeScript 靠 freeCodeCamp、openclaw 这些大项目撑场，Python 则是 public-apis、free-programming-books 这类“工具书”项目稳如老狗。**JavaScript** 只有 3 个项目上榜，但 GuJumpgate 这种新星还在用 JS 搞事，说明前端生态虽卷但没死。Shell 脚本 2 个项目垫底，看来大家越来越懒得写自动化脚本了。

💡小编视角
